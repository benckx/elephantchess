# Muted 404 URI patterns
#
# One pattern per line. Blank lines and lines starting with '#' are ignored.
# A request whose path (the part before '?') contains any of these patterns
# (case-insensitive substring match) is logged at DEBUG instead of WARN and
# answered with a plain 404. This keeps the logs free of the constant
# background noise from vulnerability scanners and automatic client probes.
#
# ElephantChess ships no PHP, WordPress, Joomla, cgi-bin, .NET or native app,
# so every pattern below can only ever come from a scanner or a benign probe.
